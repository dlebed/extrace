Every encoding

A record is hdr [tsd] [len payload]. The kind in the header decides which fields follow. The one exception is function tracing: FTRACE headers 20 and 21 carry one varint, the address, and FTRACE_CALLER headers 40 and 41 two, the address and the caller, with no length field.

Record sizes

Bytes per record for the examples above, split by field role. A function call costs 3 bytes without a timestamp and 4 with one. FRAG (516 bytes) and padding are left out.

In the ring

A 128-byte ring, one cell per byte, 16 per row. Step through a producer session: records append at the head, the consumer releases at the tail, and the ring end, alignment, drops and a cancel each leave their own marks.

head: next write tail: next read written in this step released: free space, old bytes remain

Build a record

Pick a record type and change its fields. The bytes are encoded and then decoded by the same rules as the C decoder.

Decode bytes

Paste hex from a ring dump or a bulk frame. Padding is skipped, timestamps accumulate from the last SYNC or LOST anchor. PRINTF sites 0–3 use the descriptors of the examples; other sites show their raw argument bytes.

Varints

Every number on the wire is an unsigned LEB128 varint: 7 bits per byte, low bits first, the top bit set while more bytes follow. Signed values are zigzag-encoded first, so small negatives stay short.
